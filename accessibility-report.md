### Method and limitations

The audit used the eight rubric dimensions and weights specified in this baseline. Markdown frontmatter and fenced code were parsed separately; Markdown/HTML headings, images, links, tables, callouts, and source-visible code fences were recognized. Content absent for a dimension receives 5.0. Observable source issues lower a dimension score according to the rubric severity: minor/single issues generally score 3–4, repeated/significant issues score 1–2, and no detected issue scores 5. The per-article overall is `sum(dimension score × weight)`; repository overall is the mean of unrounded per-article weighted scores. Displayed values are rounded to one decimal place. Plain-language scoring uses source prose sentence length only; it cannot reliably judge specialized terminology, sentence meaning, or first-use definitions. Table layout intent, whether link text is sufficient in context, whether an image is decorative, and alt-text equivalence cannot always be determined from Markdown alone. Findings are triage signals for manual remediation, not claims of WCAG compliance.
