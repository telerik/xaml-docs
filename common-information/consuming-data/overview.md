# Overview

__Telerik UI for {{ site.framework_name }}__ can be populated with data in any of the following ways:

* Populating with data from an [ADO.NET Data Service](https://docs.microsoft.com/en-us/previous-versions/visualstudio/visual-studio-2008/cc907912(v=msdn.10)).

{% if site.site_name == 'Silverlight' %} 
* Populating with data from a [Web (asmx) Service]({%slug consuming-data-web-asmx-service%}).

* Populating with data from a [.NET RIA Service]({%slug consuming-data-net-ria-service%}).

* Using [DomainDataSource]({%slug consuming-data-domain-datasource-support%}).
{% endif %}

* Populating with [XML data]({%slug consuming-data-using-xml%}).

* Using [in-memory data]({%slug consuming-data-in-memory-data%}).
